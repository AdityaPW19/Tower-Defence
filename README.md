# React Port (minimal)

This is an initial scaffold for the React + TypeScript port of the Svelte tower-defence game.

To run:

1. cd react-port
2. npm install
3. npm run dev

Notes:
- This initial scaffold includes core runtime classes: `GameLoop`, `Managers`, `Game`, and a ported `GameBridge` implementation.
- Next steps: implement store shim, port entities and UI components, copy `static/` assets into `react-port/public`.
